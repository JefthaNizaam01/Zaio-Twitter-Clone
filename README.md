# FakeTwitter Clone

A simple Twitter/X-style homepage clone built with HTML, CSS, and JavaScript.

## Features
- Twitter-like sidebar navigation
- Main feed with posts and tweet cards
- Right-hand sidebar with trends and suggestions
- Tweet composer modal
- Explore tab interaction
- Dark/light mode toggle
- Responsive layout for desktop and mobile screens

## Project Structure
- `index.html` - main page structure
- `styles.css` - layout and styling
- `script.js` - interactivity and UI features
- `assets/` - images and custom favicon

## Run Locally
1. Open the project folder in your code editor.
2. Launch a local preview using Live Server, or open `index.html` directly in a browser.
3. For the best experience, use a browser with local preview support.

## Notes
This project is a front-end clone inspired by Twitter/X and focuses on layout, styling, and interactive UI features.
